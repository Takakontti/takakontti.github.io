Privacy notice

Last updated: October 10, 2026

What the tracker stores

The tracker makes no account, does not request your email, and sends no character name or checklist progress to the site operator. If you affirmatively choose Allow local saving, it stores the character label you enter, checked All Ears step identifiers, your hide-checked preference, and a record of that opt-in (including its version and timestamp) in your browser’s local storage on that device. A character label could identify you if you choose a real name; use a nickname instead. The tracker does not use cookies, analytics, advertising pixels, or an application server.

The main site also stores your light/dark theme choice in this browser when you use the theme toggle. This setting contains no account identifier and is used only to remember your display preference. Clear the browser’s local site data to remove it.

If you choose Continue without saving, progress is held in memory only for the current page session and is lost when you leave or reload. No refusal choice is stored. The opt-in record is read on later visits only to remember a previous affirmative choice. Without that saved opt-in, the tracker asks again.

Purpose and legal basis

Local saving is used only to provide the progress-persistence feature you request. It is off until you opt in. The intended legal basis for this optional local processing is your consent; you can withdraw it at any time using Privacy settings, which disables saving and removes this tracker’s local-storage entries. The tracker needs no personal data to show its checklist.

Hosting and third parties

This static site is hosted by GitHub Pages. GitHub says that it logs and stores visitors’ IP addresses for security purposes when a Pages site is visited. That hosting-level collection is performed by GitHub, not by this tracker, and is subject to GitHub’s Privacy Statement. See also GitHub Pages data collection. GitHub may process data in other countries as described in its statement.

The site does not load remote fonts or embedded third-party media. External links, including the Wiki and GGG links, connect to those providers only if you choose to follow them; their privacy terms then apply.

Retention, access, and deletion

Opted-in tracker data stays in this browser until you remove it, clear the browser’s site data, or withdraw opt-in in Privacy settings. It is not synced or backed up by this tracker. The interface lets you review and change checked steps, switch the character label, and reset that character’s checklist. Clearing the consent in Privacy settings deletes all saved progress for this tracker on this origin. Browser-level copies or backups are outside the tracker’s control.

You can exercise applicable data-protection rights—such as access, correction, deletion, restriction, objection, portability where applicable, and withdrawal of consent—by using these local controls or contacting the controller at the address above. While local saving is enabled, use Privacy settings → Export my saved tracker data to download a machine-readable JSON copy. Because the tracker does not send its local progress to the controller, the controller cannot retrieve it for you. You may also complain to your competent data-protection authority.

Cookies and device storage

No cookies are set by this tracker. Local storage is a separate browser storage technology and is only written after opt-in. The initial check for a previously granted opt-in reads only the tracker’s consent record. Choosing not to opt in does not write anything. GitHub Pages or your browser may have their own hosting or security behavior outside this tracker’s control.

Changes

If the tracker’s data use changes, this notice and consent choices will be reviewed and updated before the new processing is introduced.
